# E01-01 — prova de decode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provar FLAC/MP3/WAV, trim confiável e precisão PCM24/32 com corpus pequeno e referência independente.

**Architecture:** Crate experimental `vynamp-decode`, somente worker offline, sem integração com output. Symphonia explicitamente configurada; inteiros permanecem i32 com alinhamento MSB; MP3 produz f32. Decode limitado por bytes, frames, canais e taxa; cancelamento por geração atômica. Fixtures determinísticas geradas fora do adapter, FFmpeg como encoder/oráculo independente.

**Tech Stack:** Rust 1.99.0; Symphonia =0.6.1, default-features=false, flac/mp3/pcm/wav; serde_json/sha2 somente nos testes. PowerShell para gerar corpus; FFmpeg externo na scratch, sem runtime no app.

**Spec:** [TASK-E01-01](../../../tasks/items/TASK-E01-01.md), [engine](../../audio/01-engine.md), [registry](../../audio/06-codec-capability-registry.md).
